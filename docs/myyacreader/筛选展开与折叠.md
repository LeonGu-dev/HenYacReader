# 筛选展开与折叠

筛选标题行右侧顺序：最爱、与/或、图钉。图钉与现有按钮同为 24×24 逻辑像素，使用主题文字色，无背景、无蓝色高亮；开启为图钉，关闭为图钉加斜杠。两种状态的悬浮提示均为“始终展开”。

## 交互

- 默认开启：状态按钮区始终显示，高度不足时在该区域内滚动。搜索与标签页不随之滚走，标签页继续使用自身的滚动区域。
- 关闭：显示“类型与状态”折叠行，初始收起；可单独展开/收起。折叠行显示已选状态的摘要，完整内容可以悬浮查看。
- 展开或折叠不改变筛选条件；重置所有筛选也不改变图钉偏好。
- 侧栏与智能列表编辑器直接复用同一个组件。两处图钉偏好分别保存，手动临时展开不持久化；图钉关闭时再次打开为收起状态。

## 高度处理

按钮区使用独立 QScrollArea，按可用高度限制最大高度，保持最小高度固定，避免把分配尺寸反馈为不断增长的最小尺寸。组件首选高度根据内容计算，弹窗有空间时能完整显示状态按钮。

移除侧栏筛选窗格原先 280 的固定最小高度，文件夹和阅读列表的最小高度各调整为 64；表头分隔区根据内容最小高度自适应，避免字号增大时表头越界。

智能列表编辑对话框保留原有外层滚动和底部保存/取消按钮。新增筛选字段仍接入共享组件与统一筛选模型，不维护两份界面。

## 保存位置

UI 偏好保存在当前程序配置目录的 `YACReaderLibrary.ini`：

- `libraryConfig/metadataFilterAlwaysExpandedSidebar`
- `libraryConfig/metadataFilterAlwaysExpandedSmartEditor`

不写入漫画元数据或智能列表筛选条件。
