# 清理默认列表第一轮

2026-11-09：阅读列表窗格不再显示 Favorites、Reading、Recent 三个默认行，为下一步改造用户书单让位。

## 本轮改动

- 窗格从上往下只剩：用户标签（若有）、分隔线、智能列表（若有）、用户书单。三个默认行和它们上方那条分隔线一并移除。
- 收藏改为只用元数据字段：表格最左侧爱心列、编辑页的“最爱”、筛选窗格的灰／红心。原来“把漫画拖进窗格里的 Favorites 行”这个入口随之消失，因为已经没有那一行。
- 不删除书库数据，也不升级数据库版本。`default_reading_list` 表、`SpecialListItem`、`TypeSpecialList` 以及与它们相关的导航、空状态和删除逻辑都保留：旧书库照常打开，收藏数据和阅读进度不受影响，只是这些入口暂时不再从窗格进入。
- 智能列表和用户标签本轮不动。

## 顺带修复

新增标签时，旧代码先把标签放进列表、再发插入信号，视图拿到的行数比实际少一行；插入行号也多算了一行。现在先算出标签在颜色／名称排序里的位置，再 `beginInsertRows`，最后插入。该问题由本轮新增的模型一致性检查暴露，此前没有测试覆盖。

## 代码

- `YACReaderLibrary/db/reading_list_model.*`：移除特殊列表的装载与行、顶部那条分隔线，`labelsStart()` 改为 0；新增 `labelPosition()`。
- `tests/list_model_test/main.cpp`：新增 `defaultListsAreNotRows`（无特殊行、行数为标签＋分隔线＋书单、新增标签落在正确行）；把与特殊行/收藏拖放相关的用例和行号偏移一并调整。
- `tests/sidebar_filter_test/main.cpp`：断言窗格内不存在特殊列表行。

## 验证

完整构建通过；54/54 CTest 通过。模型测试带 `QAbstractItemModelTester`，覆盖行数、插入位置和模型一致性；侧栏测试覆盖三窗格顺序、拖拽和设置持久化。
