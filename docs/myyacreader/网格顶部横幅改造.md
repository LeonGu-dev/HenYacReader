# 网格顶部横幅：紧凑资料布局

## 本轮共识

改造对象是非书库根目录的网格顶部“当前漫画”横幅，不是普通封面卡片，也不是书库根目录的“继续阅读”横排。沿用 Info view 的资料行、圆角标签、评分、最爱与状态配色。

- 左侧封面有固定的显示区域，横竖封面均等比完整显示，下面是继续阅读按钮。
- 右侧顶部为标题、翻译标题、最爱、评分、已读状态和进度。
- 资料区宽度足够时，作者/社团、作品/即卖会各占半行；角色、tag、译者占整行。窄窗口自动转为单列。
- 未填写的资料不占行，未知/未设置的状态不显示。类型、色彩、修正、翻译状态放在底部。
- tag 默认显示前四项，更多内容通过展开/收起查看；展开后横幅自然增高，下方网格随之下移，不设置固定高度裁切。
- 横幅不再显示旧卷号、期号、故事线、发行日期、Comic Vine 链接与情节简介。文件信息仍可在 Info view 查看。

## 数据与扩展

`ComicInfoObject::detailRows()` 是两处共用的资料展示配置：字段键、标签、值、颜色字段、备注，以及紧凑布局的 `compactHalf` / `compactOrder` / `compactLimit`（默认预览数量，0 为全部）。新增展示字段时在这里配置，默认整行显示。状态项共用 `statusBadges()`。

`ComicInfoView.qml` 同时承担普通 Info view 和横幅紧凑布局；`compact` 只影响排列、tag 展开及文件信息的默认可见性。颜色直接使用现有 `MetadataChipColors`，不另建配色副本。`CurrentComicBanner.qml` 仅负责封面、继续阅读按钮与整体响应式布局。

增加既有字段的取值仍需更新其状态展示配置；新增真正的元数据字段仍需完成存储、编辑、筛选等相应工作。复用展示配置不意味着这些业务层会自动生成。

## 横幅漫画和操作

保持原有显示条件：当前模型中的第一本未读漫画；仅文件夹/普通阅读列表、未启用筛选且设置允许时显示。书库根目录仍使用原继续阅读横排。

横幅操作使用独立的模型行号，不依赖用户当前选中的封面卡片。初始最爱值读取现有元数据；评分、最爱与已读变化后刷新横幅。标记已读后，按原规则显示下一本未读漫画。

- 将封面与资料整体限制在左侧 860 逻辑像素内，资料不再随大屏无限拉开。
- 紧凑横幅中的爱心跟随标题，普通 Info view 保持原来的右侧爱心布局。
- 横幅铺设当前主题信息面板底色，92% 不透明度（保留少量封面背景），不对文字和标签整体设置透明度。
