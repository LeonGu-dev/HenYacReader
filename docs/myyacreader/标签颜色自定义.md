# 标签颜色自定义（待用户验收）

为作品、角色、tag 的圆角色块添加右键首项“更改颜色”，保留现有漫画菜单操作。颜色选择器使用 QColorDialog 默认原生选项，在 Windows 请求系统颜色选择器；不启用 alpha，不强制 Qt 自绘对话框。

菜单关闭后以排队连接打开颜色选择器，避免菜单持有原生模态窗口。按实际绘制的色块区域命中完整字段值；保存对象是字段和值，不依赖弹出菜单时的行号或当前选择。

同一配置内同字段、同值共享颜色。自定义值写入 YACReaderLibrary.ini 的 metadataChipColors，键为稳定字段名加内容 SHA-256，支持名称中的斜线及其他特殊字符。读取配置后在内存缓存，绘制时不反复读取文件；成功保存后通知所有委托刷新。取消不写设置；保存失败显示错误。未自定义的内容继续使用上一轮的稳定默认颜色。

背景颜色确定后根据线性 sRGB 亮度选择黑色或白色文字。设置独立于漫画数据库和压缩包，不做数据结构升级。

## 代码

- custom_widgets/metadata_chip_colors.*：配置缓存、持久保存、字段隔离、默认色和文字色。
- custom_widgets/metadata_chip_delegate.*：使用配置颜色、实际命中检测及刷新。
- custom_widgets/yacreader_table_view.*：首项动作和原生选色器；可替换的受保护选择方法用于测试确认/取消。
- ComicsView / ClassicComicsView / LibraryWindowMenus：将该动作加入原有行菜单，并修正视口坐标转换。

## 英文、数字标签显示修复

标签宽度改用实际绘制字体和绘制设备的 QFontMetricsF 重新测量，向上取整并留少量像素余量。能够完整放入的文本直接绘制完整值，仅空间不足时执行省略；短标签不再因为最小省略空间门槛被提前隐藏。左键和右键均使用同一份初始化后的字体与色块布局命中。

新增实际绘制文本及边界检查，覆盖 7 种字号、英文/长数字/中英混排、字体变化后缓存度量陈旧、窄列省略和重新拉宽恢复。表格 Qt Test 合计 58 项通过，原有调色、取消、持久化和第二个标签命中检查也通过。打包程序完成隔离无界面启动检查。

最新入口为 artifacts/table-v1/启动标签显示修复版.cmd；原“启动标签调色验收.cmd”也指向修复版。复用原 profile，自定义颜色保持。
