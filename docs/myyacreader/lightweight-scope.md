# 后续轻量化范围

普通漫画信息编辑已经简化为单页。旧数据库列及上游其他功能仍保留，避免破坏既有数据和非普通编辑流程；尚未进行大规模模块删除。

| 模块 | 当前处理 | 后续需要决定 |
| --- | --- | --- |
| 解压、图片解码、显示、阅读进度 | 保留 | 继续作为阅读器核心 |
| 书库扫描、封面、SQLite、检索 | 保留 | 优化常用整理入口 |
| Library / Reader 本地通信 | 保留 | 与网络服务区分 |
| 普通信息编辑 | 已简化 | 已录入值勾选与筛选 |
| Comic Vine | 保留 | 是否移除或改为可选构建 |
| 内嵌网络服务及独立 Server | 保留 | 是否保留手机/网络访问 |
| 3D Cover Flow | 保留 | 是否移除对应 UI、RHI 与 shader 依赖 |
| 缺期追踪、占位漫画、复杂阅读列表 | 保留 | 是否裁剪对应记录模型及入口 |
| PDF / EPUB | 保留 | 实际格式范围确认后再调整 |

每轮只处理经确认的范围。删除控件与缩减程序体积是不同工作；体积、启动和内存变化需要单独测量。

代码入口：`YACReaderLibrary/properties_dialog.*` 负责编辑对话框；新表单、文件名和改名逻辑分别在 `comic_metadata_editor.*`、`comic_filename.*`、`staged_comic_rename.*`。更早的源码定位与讨论见 [历史稿](history/lightweight-scope.md)。
