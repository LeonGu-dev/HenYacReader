# 阅读列表改造第一轮

2026-11-09：阅读列表窗格顶部恢复两个固定来源行，规则重做，名称改为中文；窗格背景跟随主题。

## 两个固定行

| 行 | 规则 |
| --- | --- |
| 正在阅读 | 打开过且未读完（`hasBeenOpened = 1 AND read = 0`），按最后阅读时间倒序，**最多 20 本**。不设时间窗口：离开阅读一段时间后仍能看到最近在读的那批。 |
| 最近添加 | 最近 **7 天**入库，按入库时间倒序，不设上限。 |

与旧实现的区别：旧的「正在阅读」没有上限也没有时间窗口，等于「所有没读完的漫画都堆在这里」；旧的「最近添加」沿用设置项 `NUM_DAYS_TO_CONSIDER_RECENT`（默认 **1 天**），平时基本为空。这两个值现在是各自模块里的常量，以后需要再挪进设置。

两个行名直接使用中文（`tr("正在阅读")` / `tr("最近添加")`）。Favorites 不再有行：收藏是漫画元数据字段，入口在爱心列、编辑页和筛选窗格。

## 外观

- 文件夹树和阅读列表树不再各自绘制白底，改为透出侧栏背景色；树视图去掉边框。深色主题下窗格不再出现白色区块。
- 固定行与用户书单之间保留一条分隔线。

## 代码

- `YACReaderLibrary/db/reading_list_model.cpp`：恢复 `setupSpecialLists()`，只生成两行；恢复特殊行与顶部（仅一条）分隔线的行计算。
- `YACReaderLibrary/db/comic_model.cpp`：`createReadingModelData()` 加 `LIMIT 20`；`createRecentModelData()` 改用 7 天常量。
- `custom_widgets/yacreader_sidebar.cpp`：两个树视图关闭自动填充背景、去掉边框。
- 测试：`defaultListsAreTheTwoFixedRows` 覆盖两行名称、类型、行数与新增标签的行位置；侧栏测试断言两行存在且 Favorites 不存在。
