# 漫画信息编辑需求（当前确认版）

根据用户修改的模板及后续 8 项答复整理。当前已验收面板保留下列 11 项信息，集中在一个页面中。

## 字段

| 字段 | 定义 | 示例 | 数量与填写规则 |
| --- | --- | --- | --- |
| 标题 | 漫画的主标题，不限定语言 | プロトタイプロリータ | 单个；不要求唯一；只有中文标题时直接填中文 |
| 翻译标题 | 主标题对应的译名 | （按实际译名填写） | 单个；可不填；不是文件名，也不是独立记录的唯一键 |
| 作者 | 漫画作者 | 40010壱号 | 默认单作者；勾选“合同本”后，使用可通过 `＋ / －` 增删的多作者列表；每位作者都能单独被检索到 |
| 社团 | 作者所属的社团 | 40010試作型 | 单个；可不填 |
| 作品 | 漫画内容所属的原作 / IP | ブルーアーカイブ | 单个；可选“原创”；允许未设置 |
| 角色 | 漫画登场的角色 | 橘爱丽丝 | 允许多个；原创漫画统一标为“原创”；允许未设置 |
| tag | 用户录入的内容标签 | 纯爱 | 允许多个；不需要别名或同义词体系 |
| 彩色/黑白 | 漫画的色彩类型 | 彩色 | `未设置`、`彩色`、`黑白` |
| 无修正 | 漫画的修正状态 | 有码 | `未设置`、`有码`、`无修` |
| 翻译 | 漫画的翻译状态 | 日文 | `未设置`、`日文`、`中译`、`AI 翻译` |
| 译者 | 翻译者或汉化组 | xxx个人汉化 | 单个；可不填 |

## 作者与“合同本”

- 勾选“合同本”后显示多作者列表，右侧使用 `＋ / －` 增删作者。
- 取消勾选时，暂存原多作者列表，避免误操作立即丢失。
- 取消勾选并保存后，以新的单作者覆盖原作者集合，删除这本漫画原先保存的其他作者关联。
- 这里的删除仅指当前漫画的作者关联，不删除作者在其他漫画中的信息。
- 多作者中的每位作者都能用于查找这本漫画。

## “原创”联动

- 按第 6 项答复理解：作品或角色任一选择“原创”，二者同步标为“原创”。
- 原创状态不与具体 IP 或具体 IP 角色同时存在。
- 编辑中的联动在保存后写入书库。

## 检索与以后复用已录入内容

- 标题允许重复，文件名与标题分开管理；沿用独立文件记录和漫画信息记录的标识。
- 不增加作者、社团、作品、角色或 tag 的别名体系。
- 后续增加已录入 **tag / 作品 / 作者** 的列表选择功能，便于点击勾选并复用现有值。
- 作品为单选；tag 可多选；作者在合同本模式下可多选。
- 已录入值的选择列表尚未实现，后续再设计。

## 保存位置

- 元数据保存在当前书库的 `.yacreaderlibrary/library.ydb` SQLite 数据库中。
- 同目录的封面等配套资料仍由书库管理。
- 默认仅保存书库元数据；明确勾选重命名后随保存修改压缩包文件名，压缩包内部内容不改动。数据库结构版本已升级为 10.5.1。
- 两个文件名如果被上游识别为同一内容，目前会共享漫画信息。识别与存储核对见 [漫画识别与存储说明](漫画识别与存储说明.md)。
