# 元数据筛选第一轮（待验收）

在左侧文件夹与阅读列表之间增加“筛选”窗格，三个区域可拖动分隔线调整高度。初版功能已由用户验收，当前继续调整分类栏外观并增加评分筛选。

## 操作

- `tag`、`作品`、`作者`三个标签页显示当前书库已录入的内容，去空白、去重后排序。
- 分类切换栏等宽铺满窗格，顶部搜索框与分类栏之间增加留白。
- 新增“评分”分类，复用表格的星星绘制，按 5 星至 1 星逐行显示。选中行使用淡蓝色背景，再次点击取消。
- 评分可多选，评分内部始终为“或”，评分与其他筛选结果始终为“与”，不受下方与／或按钮影响。未评分不匹配 1～5 星；编辑评分后会重新检查当前筛选结果。
- 候选项以圆角色块平铺，tag、作品复用右侧表格的颜色设置。作者使用同一套默认配色算法。
- 内容页与滚动视口透明，透出侧栏主题颜色，取消原先独立的背景色块。滚动条沿用 Qt／Windows 原生样式，本轮未调整其粗细。
- 点击色块选中，再次点击取消；明亮外观显示黑色描边，暗黑外观显示白色描边。
- 顶部搜索框只搜索候选项，支持部分匹配，不改变已选条件。
- “与搜索”要求所有已选 tag、作品、作者同时满足；“或搜索”要求至少一个满足。按完整条目匹配，例如 `daily` 不会命中 `daily-extra`。
- 黑白／彩色、有码／无修正、中译／AI翻译／无翻译，每组至多选一个，再次点击取消。不选择的组不限制结果。
- 底部三组与上方筛选结果始终取交集，且三组之间也取交集。
- 最下方“重置所有筛选”清空 tag、作品、作者、评分与全部状态条件，同时清空候选项搜索框，恢复默认“与搜索”，显示当前来源的完整列表。

## 范围与数据

- 候选项来自整个当前书库；筛选结果作用于右侧当前文件夹、阅读列表或已有搜索结果。
- 切换同一书库内的文件夹、阅读列表时保留筛选条件；切换书库时清空条件。
- 取消所有条件后恢复当前来源的完整列表。筛选不修改漫画信息或文件，也不向旧 Label 写入任何内容。
- “无翻译”匹配元数据的原文（日文）状态 `original`；未设置翻译状态不自动当成无翻译。彩色和修正状态同理，不猜测未设置内容。
- 筛选生效时禁用列表拖动排序，避免只对部分可见成员重新写入顺序。
- 这一轮暂不保存筛选条件到下次启动，保留旧 Label 功能，等待验收后继续处理。

## 实现位置

- `custom_widgets/metadata_filter_panel.*`：窗格、候选项绘制与交互。
- `custom_widgets/yacreader_sidebar.*`：三个窗格布局及分隔线位置保存。
- `YACReaderLibrary/db/metadata_filter.h`：精确条目匹配及组合规则。
- `YACReaderLibrary/db/comic_model.*`：当前来源筛选、取消恢复、候选项读取及缓存。
