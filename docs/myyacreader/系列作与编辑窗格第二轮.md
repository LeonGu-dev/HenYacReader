# 系列作与编辑窗格第二轮

## 已确认的设计

保留单页编辑。标题和翻译标题下方是一行评分与最爱，窗口右上角保留系统关闭按钮。作者行标题右侧放合同本开关；系列行标题右侧放系列作开关。

系列作不弹对话框：开启后原位显示单值输入，点击输入框展开当前书库已有系列，可连续改选或录入新名称；不提供铅笔按钮。取消开关时保留本次输入以防误操作，保存时取消则清空系列。作者合同本仍保留原有“误取消再开启可恢复，取消后保存以单作者覆盖”的规则。

角色、tag、合同本作者使用同一套彩色标签输入；候选区点击标签不收起，点箭头、切换字段或点空白处才收起。已选择标签中的 × 移除该值；输入后回车加入标签，回车不触发整个窗口保存。状态选项再次点击可取消，省去重复的“未设置”按钮。

## 评分保存边界

复用原 `comic_info.rating`（0–5），不重复创建评分字段。抽出列表原有 `StarRating` 绘制代码供轻量 `DraftRating` 使用；不嵌入 Qt Quick，不连接列表的即时提交信号。

星级点击只改变草稿，重复点击当前等级清零。元数据保存时通过仅修改 rating 的 SQL 与其他字段共用一个事务，任何写入失败整批回滚。批量评分不同时保留各自原值，明确点击后才统一覆盖；包含不支持评分的占位条目时禁用评分。

## 系列数据与筛选

新增可空的 `seriesName`，独立于旧版 `series/number/volume`，避免触发旧标题回退、编号及交换逻辑。只存一个系列名，开关状态由名称是否为空表示。不增加表格列，也不将系列自动写入文件名。

数据库版本升为 10.5.5，为 comic_info 与 placeholder 添加可空字段。迁移不改旧系列、评分、文件名或其他个人数据。候选查询仍使用当前书库的独立只读连接。

筛选新增“系列”页签，在即卖会后、评分前，沿用圆角颜色、搜索和多条件与/或逻辑。智能列表共用 MetadataFilterPanel，保存条件增加可选 seriesNames；旧智能列表缺少该键时按未选择处理。

Info view 与网格横幅从共用展示配置读取系列；不新增表格列。

## 独立重命名

默认不显示新文件名。点击“生成文件名”后，底部显示含原扩展名的可编辑结果、右侧“重命名文件”和预览标题右侧 ×。× 关闭并清空预览，关闭不执行操作。

“重命名文件”独立确认，立即更新文件及当前书库路径记录，不保存待编辑的标题、系列、评分等。已有文件冲突、非法名称或扩展名变化会拒绝；数据库失败时恢复原名。成功后保留其他草稿，之后可以继续保存或关闭编辑窗口。

已确认的重命名不会因随后取消元数据编辑而撤销。元数据“保存”不再承担重命名职责，移除旧的“保存时重命名”复选框及相应保存分支。

## 紧凑布局与八项优化

- 作品与角色并排，共用一行高度；角色仍可换行容纳多个标签。
- 译者移至社团/即卖会下方、作品/角色上方，归入创作信息区。
- 翻译标题新增启用开关：有值默认展开，无值默认折叠；混合值保持不变。关闭保留草稿以便恢复，明确关闭并保存才清空字段。
- 合同本作者、角色、tag 的录入光标改到标签同行；不足一行时自然换行，不再固定留出一整行空白输入。
- 减少普通输入的垂直内边距及字段间距；多值区按实际标签行数决定高度。
- 分隔线改为中性灰色半透明细线，避免部分原生浅色调色板将 midlight 渲染为白色。
- 移除星级焦点下方的蓝线，保留键盘操作能力。
- 解析与生成文件名按钮采用中性灰色浅底及灰色边框，悬浮加深；不改变文件名预览和独立重命名流程。
