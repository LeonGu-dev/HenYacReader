# 漫画阅读器改造方向

## 已确认的目标

- 以 YACReader 的主要代码为基础开发。
- 保留 Library 与 Reader 分离的设计：书库负责整理与查找，阅读器负责阅读。
- UI 参考 Rulia 的视觉与交互方向，具体布局和样式待设计。
- 支持标签管理和检索、漫画基础信息整理和检索、智能文件名识别及重命名、自动翻页。

## 建议的功能行为（待细化）

### 书库与信息整理

- 书架提供封面网格、搜索框、标签筛选和漫画详情入口。
- 详情优先显示标题、系列、作者、卷/话、标签、简介和阅读状态。
- 支持多选编辑；批量添加或移除标签时保留其他标签。
- 标题、作者、标签可组合筛选；标签支持“全部满足”“任意满足”和排除条件。
- 元数据优先复用现有 SQLite 和 ComicInfo.xml 导入机制；新增内容需定义覆盖优先级及兼容策略。

### 文件名识别与重命名

- 工作流：选择文件 → 识别候选信息 → 修正信息 → 预览新名称 → 应用。
- 先以可解释的规则识别作者、标题、卷/话、语言等；无法判断的内容标记待确认。
- 规则应基于用户实际文件名样本制定；“智能”不预设为必须接入云端 AI。
- 元数据修改与物理重命名分开操作，允许只整理书库显示信息。
- 重命名复用上游计划与日志机制，处理同名冲突、非法字符以及数据库路径同步，并核实撤销流程。
- 参考命名模板：`[作者] 标题 第01卷.cbz`，具体规则可配置。

### 自动翻页

- 第一版按固定时间间隔翻页，提供开始、暂停和间隔设置。
- 手动翻页后重新计时；打开菜单、弹窗或窗口失去焦点时暂停。
- 默认到当前漫画末页停止；是否自动进入下一本另设选项。
- 连续滚动模式下的匀速滚动作为独立行为评估。

## 建议实施顺序

1. 验证 Windows 构建与现有功能，建立可运行基线。
2. 设计并落地书库、详情与阅读器工具栏的 UI。
3. 完成标签管理、批量信息编辑和可视化组合检索。
4. 接入文件名识别到现有重命名预览流程。
5. 增加自动翻页，验证与手动翻页、末页、菜单和进度保存的交互。
