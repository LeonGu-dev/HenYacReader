# 漫画信息第一轮改造记录

依据：[当前确认的编辑需求](../漫画信息编辑模板.md)。

## 已完成

- 普通漫画信息编辑改为单页，显示确认的 11 项信息。
- 作者支持单作者 / 合同本切换；多作者列表可通过 `＋ / －` 增删。
- 取消合同本时保留暂存列表；以单作者模式保存时覆盖当前漫画的作者集合。
- 角色和 tag 支持多项录入；社团、作品、译者保持单项。
- 作品和角色支持“原创”双向联动；从原创改回具体 IP 时清空“原创”角色值，等待重新填写。
- 彩色/黑白、修正状态、翻译状态均支持“未设置”。
- 保存、重新加载及批量字段更新沿用事务与局部更新机制。未修改的字段不覆盖其他漫画的不同值。
- 标题允许重复；原有不同文件共享漫画信息的关系保持不变。
- 新字段接入现有检索，作者名单中的每位作者都可检索。
- 阅读器回传进度时保留书库中最新的全部描述信息，避免旧快照覆盖编辑结果。

## 数据结构

数据库版本从 10.5.0 升为 10.5.1。新增字段如下，均在原书库数据库内：

| 字段 | 内容 |
| --- | --- |
| `translatedTitle` | 翻译标题 |
| `circle` | 单个社团 |
| `work` | 单个作品 / IP |
| `isAnthology` | 是否合同本 |
| `censorship` | `censored` / `uncensored` / NULL |
| `translationStatus` | `original` / `translated` / `ai` / NULL |
| `translator` | 单个译者或汉化组 |

标题、作者、角色、tag、彩色状态分别复用 `title`、`writer`、`characters`、`tags`、`color`。多值字段按换行分隔，输入时清除首尾空白并去除重复项。

升级采用新增列，保留现有字段、文件关联、标题、阅读进度和已有信息。旧的专业字段不出现在普通编辑面板中，数据库暂保留以兼容现有收藏。

没有扩展阅读器现有的二进制通信格式；由书库保存回传进度前保留已有描述信息。
