## 推荐的简化编辑面板

将五个页签收敛为一个面板，优先展示：

- 封面。
- 标题。
- 作者；可先在界面简化展示，具体与 writer / penciller 的映射需确定。
- 系列、卷 / 话（按需要填写）。
- 标签：可选择、添加、移除，批量编辑可追加或移除而非只能整体覆盖。
- 简介和备注（可折叠）。
- 路径、格式、页数、大小等作为只读文件信息。

建议从常用界面移除：故事线、故事线编号与总数、备用系列及其编号、系列组、多种制作人员角色、详细出版字段、人物 / 团队 / 地点等。

现有数据字段先保留，简化编辑器只提交实际修改的字段。这样可以缩小 UI 改造范围，并保留已有漫画资料和 ComicInfo.xml 导入的兼容基础。单纯删除字段行不可直接完成改造，因为加载、批量编辑和保存代码仍引用相应控件。

## 功能和依赖裁剪候选

| 类别 | 建议 | 注意点 |
| --- | --- | --- |
| 文件打开、解压、图片解码、渲染、缩放、进度 | 保留 | 阅读器核心 |
| 书库扫描、封面缓存、SQLite、标签与检索 | 保留并优化入口 | 管理核心 |
| Library / Reader 本地通信 | 保留 | 与面向网络的书库服务器区分 |
| 元数据驱动重命名 | 保留底层 | 接入新的文件名识别流程 |
| 详细元数据编辑 | 优先简化 UI | 不直接删除数据库列 |
| Comic Vine 在线资料抓取 | 候选移除或构建可选 | 需同时处理菜单、协调器和链接依赖 |
| 网络书库服务、手机访问及服务器配置 | 候选移除或构建可选 | GUI 当前链接 server；仅不构建独立 Server 程序不能移除内嵌服务 |
| 3D Cover Flow 展示 | 候选移除 | 关联 Library 与 Reader 的 flow 控件、RHI 库及 shader；普通封面网格和缩略图另行保留 |
| 缺期追踪与占位漫画、复杂阅读列表 | 待用户决定 | 已进入记录模型和编辑器，不能只删一个对话框 |
| PDF、EPUB 等格式 | 待确认实际使用范围 | 格式支持影响依赖，未确认前不裁剪 |

轻量化应分别验证界面复杂度、安装体积、启动时间和内存使用；减少输入框不能证明内存或体积下降。若使用 QML 实现现代界面，Qt Quick 仍可能需要保留。

## 推荐开发方式

采用现有 YACReader 仓库作为派生项目，保留上游历史和许可证；无需现在把底层代码抽出重写。当前只做了 shallow clone，可在需要追溯历史时补全。

进入开发阶段后：

1. 在现有 clone 内创建开发分支，并将官方远程命名为 upstream；需要发布时再添加用户自己的 origin。尚未执行这些变更。
2. 验证未修改版本的 Windows 构建、打开漫画、书库启动阅读器和进度回传，记录基线。
3. 先改造信息编辑面板，验证单本 / 多本编辑和未修改字段保留。
4. 确定书架与阅读器的整体 UI，改造标签筛选和详情入口。
5. 将不需要的模块逐项改为可选构建或移除，并比较安装体积与运行开销。
6. 加入文件名识别、重命名流程和自动翻页。

目录安排可以在正式开发前调整；当前 `upstream/yacreader` 是可直接开发的 Git 工作区，并非只能用于参考。
