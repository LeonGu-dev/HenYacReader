## 封版前建议补齐

新检查出的同类异常处理缺口：

| 位置 | 问题 |
| --- | --- |
| `YACReaderLibrary/db/comic_model.cpp::setComicsRead()` | 批量已读／未读没有检查事务、更新和提交结果，仍更新界面；失败时可能显示与数据库不一致。 |
| `YACReaderLibrary/db/comic_model.cpp::setComicsType()` | 漫画阅读方式更新存在相同问题；此字段不是同人志／单行本等出版类型。 |
| `YACReaderLibrary/comic_management_coordinator.cpp::setComicUnread()` | 继续阅读里的设为未读调用旧更新接口，未检查写入结果便刷新界面。 |

以上来自代码检查，本轮没有针对这些路径注入数据库失败。建议按已经完成的评分处理方式统一为成功后更新、失败提示；批量操作失败整体回滚，并增加针对性测试。不需要新增产品规则。
