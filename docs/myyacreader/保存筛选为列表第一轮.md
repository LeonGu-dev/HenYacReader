# 保存筛选为列表第一轮

阅读列表窗格仍位于三个窗格的最下方。本轮调整入口，并接入元数据筛选的保存功能。

## 界面

- 隐藏书单及漫画右键菜单中的“匹配到库漫画”，保留实现。
- 阅读列表标题右侧移除旧 tag、铅笔按钮，保留加号和删除。
- 加号菜单增加“保存筛选为智能列表”“保存筛选为普通列表”，输入名称后保存。
- 隐藏旧“新建智能列表”、搜索菜单中的旧语法保存入口；保留旧实现和已有语法书单的读取能力。
- 智能列表右键的旧语法编辑入口暂时隐藏。重新选择 tag 等条件的编辑界面留到下一轮。

## 保存规则

普通列表保存右侧当前显示的有文件漫画，按显示顺序建立静态书单。重复出现的同一漫画信息只加入一次；沿用现有书单关联漫画信息的方式。缺失文件及占位条目不作为本轮快照输入。空结果给出提示，不创建空快照。以后改变筛选条件或元数据，不会自动改变这份普通书单的成员。

智能列表保存筛选窗格的 tag、作品、作者、与／或逻辑、评分集合、最爱、类型、黑白／彩色、修正和翻译条件。重新打开或刷新时，在当前书库全部现有漫画中动态匹配。评分内部取或，评分及状态条件与其他条件取交集，沿用当前筛选实现。

智能列表保存时可选“作用于整个书库”或“作用于当前文件夹”。在真实文件夹视图下，默认选择当前文件夹并显示目录路径；在阅读列表、智能列表、最近添加等其他来源下，当前文件夹选项禁用，默认整个书库。下方提示“筛选智能列表基于文件夹或库，无法基于阅读列表”。

文件夹范围与普通文件夹视图一致，只包含直属漫画，不递归包含子目录；范围始终与元数据条件取交集，不受与／或按钮影响。保存目录 ID，目录改名后仍可使用；目录删除后结果为空，不会退回全库。新增或移入该目录且符合条件的漫画会动态出现。

主搜索框的文字条件不保存。筛选窗格内部的搜索框只用于寻找可勾选标签，也不保存为条件。若需要保存当前右侧结果，使用普通列表入口。

两种列表均在书单对应区域的顶层创建。取消输入或空白名称不写入。普通书单创建与所有条目写入在同一事务中完成，失效漫画或写入错误会整体回滚。不会移动、重命名或复制压缩包。

## 存储

无新增数据库表或版本升级。智能列表在原 `smart_list.query` 列中保存带版本标记的 JSON；新增范围选择后使用 `myyacreader:metadata-filter:v2:`，文件夹范围另存 `folderId`。继续读取 v1 的全库筛选和旧搜索语法；桌面和服务端共用 `ComicItems::loadSmartList`，避免出现两套匹配结果。
