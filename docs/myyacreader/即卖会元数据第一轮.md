# 即卖会元数据第一轮

即卖会为可留空的单值字段，保存在书库 `.yacreaderlibrary/library.ydb`，不写入压缩包内文件。数据库从 10.5.3 升级到 10.5.4，同时为漫画及占位条目补充字段，保留已有内容。

- 编辑页位置：翻译标题 → 即卖会 → 最爱。
- 列表默认位置：爱心 → 即卖会 → 标题。即卖会为彩色圆角标签，复用标签颜色机制，支持右键更改颜色、列显示/隐藏及排序。
- 筛选页顺序：tag、作品、作者、即卖会、评分。即卖会参与上方标签的与/或逻辑；评分和状态仍独立与筛选。
- 智能列表编辑器直接复用 MetadataFilterPanel，因此同步出现即卖会页；保存的条件包含即卖会，重置会清除它。

## 文件名

示例：`(c107) [社团 (作者)] 标题 (作品) [中国翻訳] [無修正] [译者].zip`。

解析文件名最前面的圆括号作为即卖会，支持全角括号及例大祭等名称；不会把标题后方的作品名当作即卖会。没有识别到即卖会时保留原值。生成文件名时，在作者/社团之前加入 `(即卖会)` 并以一个空格隔开。解析仍是启发式，保存重命名前可修改预览。
