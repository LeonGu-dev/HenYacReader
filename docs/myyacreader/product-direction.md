# 项目方向与当前范围

以 YACReader 主要代码为基础，保留书库和阅读器独立进程。先用小步改动完成核心功能及裁剪，每轮由用户验收，再继续下一项；整体界面最后参考 Rulia 改造。

## 已验收

- 单页编辑 11 项漫画信息；单作者/合同本、多个角色和 tag、原创联动。
- 彩色/黑白、无修正和翻译状态用单选按钮，保留未设置。
- 多值项只在最后一行显示加号；其余行输入框延伸至减号左侧。
- 封面区限制宽度并等比居中显示，横竖封面切换不改变右侧布局。
- 文件名启发式解析、编辑字段生成新名称、可修改预览、保存时确认改名并同步书库路径。
- 元数据保存、检索、数据结构升级及阅读进度回传保持兼容。
- 书库初始化弹窗和中文 MSVC 增量编译漏依赖导致的启动问题已修复。

## 后续

1. 从已有作者、作品、tag 列表点击选择，减少重复输入。
2. 根据真实样本继续调整文件名解析规则与筛选交互。
3. 由用户逐项确认需要裁剪的模块；分别验证功能、体积和运行开销。
4. 增加自动翻页；具体暂停、末页与连续阅读行为再确认。
5. 最后统一书架、详情和阅读器 UI 风格。

当前主要在 Windows / Qt 6.9.3 / MSVC 2022 验证。未声称已完成其他平台构建或已实现上述后续功能。
