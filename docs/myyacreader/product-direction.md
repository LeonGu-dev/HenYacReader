# 项目方向与当前范围

以 YACReader 主要代码为基础，保留书库和阅读器独立进程。先用小步改动完成核心功能及裁剪，每轮由用户验收，再继续下一项；整体界面最后参考 Rulia 改造。

## 当前已实现

- 单页元数据编辑，增加即卖会、系列、最爱和评分；支持已有标签候选点选、合同本、多值标签及原创联动。
- 彩色/黑白、修正、出版类型和翻译状态用按钮选择，可取消为未设置。
- 多值项以可删除的圆角标签展示，支持连续点选和手动输入；单值项并排、多值项独占一行。
- 封面区限制宽度并等比居中显示，横竖封面切换不改变右侧布局。
- 文件名启发式解析、按元数据生成可修改预览；独立确认重命名并同步路径，不再随元数据保存改名。
- 元数据列、颜色自定义、列宽记忆、侧栏筛选及普通/智能阅读列表；智能列表编辑复用筛选组件。
- Info view 和网格顶部横幅显示新版资料；旧入口逐项关闭，部分旧代码隔离参考。
- 元数据保存、检索、数据结构升级及阅读进度回传保持兼容。
- 书库初始化弹窗和中文 MSVC 增量编译漏依赖导致的启动问题已修复。

## 后续

1. 补齐新增元数据导出/导入、即时评分写入失败处理；明确“删除元数据”的清除范围。
2. 统一残留编号展示、决定旧语法智能列表兼容方式，完成全量回归和阶段归档。
3. 根据真实样本调整解析和筛选；按实际依赖裁剪模块并增加大库性能验证。
4. 增加自动翻页；具体暂停、末页与连续阅读行为再确认。
5. 最后统一书架、详情和阅读器 UI 风格。

当前主要在 Windows / Qt 6.9.3 / MSVC 2022 验证。未声称已完成其他平台构建或已实现上述后续功能。

上述为代码范围说明，不替代每轮用户验收。详细现状和风险见 [书库阶段总结与遗留审查](书库阶段总结与遗留审查.md)。
