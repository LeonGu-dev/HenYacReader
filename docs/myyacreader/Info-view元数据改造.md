# Info view 元数据改造

## 展示与交互

采用已确认的「紧凑资料行」。保留 Info view 上方封面流，仅替换下方单本漫画详情；网格视图复用的 ComicInfoView 同步更新。

- 标题使用标题或文件名回退，不再添加旧期号；翻译标题单独一行，空值隐藏。
- 右上角显示最爱，标题下方显示评分、已读开关、阅读进度。写入现有书库，不写漫画压缩包。
- 资料行依次为作者、社团、即卖会、作品、角色、tag、译者；合同本在作者下标注。
- 即卖会、作品、角色、tag 复用列表与筛选的标签颜色及自定义配置；修改颜色时即时同步。
- 类型、彩色/黑白、修正状态、翻译状态集中显示；未设置不推测，不显示状态块。
- 文件信息默认折叠，展开显示文件名及库内路径；摘要显示页数和文件大小。
- 文本按纯文本绘制，长标题、无空格英文和长标签自动换行；窄宽度时状态/操作换行。沿用外层纵向滚动。

## 兼容与扩展

不修改数据库格式、文件名规则或过滤条件，兼容现有书库。缺失文件和占位条目继续通过 ComicRecord 读取可用元数据；没有对应状态或文件时不生成虚假值。最爱写入复用 ComicModel::setFavorite；Info view 监听当前行更新，切换到空模型清空旧详情。

展示数据集中在 `YACReaderLibrary/comic_info_object.cpp`：

1. `metadata()` 自动遍历 DescriptiveComicMetadata::columns()，供标题等特殊区域取值。
2. `detailRows()` 是资料行配置：字段键、翻译标签、成员指针、颜色分类、是否多值。新增普通展示字段时，在这里登记即可，QML 不必再增加一套控件。
3. `statusBadges()` 集中登记枚举值及显示名称；NULL 和未知值不猜测。
4. `fileDetails()` 负责文件信息。

`YACReaderLibrary/qml/ComicInfoView.qml` 统一处理字段行、空值隐藏、换行、颜色、字体与布局。新增可编辑或可筛选的元数据仍需分别接入原有存储、编辑器和筛选模块；本轮不承诺未知字段无需定义就自动生成编辑和筛选功能。

颜色来自 `MetadataChipColors::colorsForField()`。新增一种彩色字段需登记其颜色分类映射，沿用既有持久化机制；无需新建颜色配置文件。
