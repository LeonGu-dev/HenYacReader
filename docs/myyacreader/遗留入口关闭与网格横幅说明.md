1. 关闭旧文件整理开关，文件夹树和网格文件夹的「重命名文件／整理到文件夹」菜单以及相应快捷键配置不再提供。物理文件夹本身的重命名仍保留；漫画文件改名继续使用元数据编辑页。
2. 漫画「添加到…」不再列出旧标签。保留其中写入当前最爱元数据的 Favorites 操作。旧标签数据库和兼容读取未删除。
3. 下载 Comic Vine 标签、分配序号、新建旧标签、旧文件重命名/整理动作隐藏、清空运行时快捷键，并从快捷键配置移除。保留配置文件中的历史偏好，不删除用户设置数据。
4. 设置的常规页不再创建 Comic Vine API key 按钮/分组。底层 API 对话框及抓取代码本轮保留。

本轮未修改网格信息卡、XML 导入导出、网络服务或 CBL 交换。

## 网格信息卡的准确位置

前一轮检查中称作「封面网格选中漫画信息卡」的旧区域，实际是网格顶部的「当前漫画／继续阅读」横幅。它来自 `GridComicsView.qml` 的 `currentComicView`，与右侧「显示信息」侧栏不同；后者的单本详情已经使用新的 ComicInfoView。

进入方法：

1. 右上角四宫格切换到网格视图。
2. 在左侧文件夹树进入一个实际的子文件夹，里面至少有一本未标记为已读的漫画。
3. 滚动到网格最上方，查看大封面、标题/简介与 Read 按钮组成的横幅。
4. 若未显示，打开设置 → 网格视图 → 继续阅读，启用「显示当前漫画横幅」，保存后重新进入该文件夹；清空搜索/筛选再试。

源码显示条件：模型为 Folder 或普通 ReadingList、找到未读漫画、未处于搜索过滤模式、不是阅读列表文件夹卡片模式、上述设置启用。书库根视图使用另一种全库继续阅读头部，因此用实际子文件夹最容易定位。

`currentComicFromModel()` 取的是当前模型中第一本未读漫画；不是跟随任意封面单击选中的漫画。这也解释了为何用户可能找不到该区域。关闭遗留入口这一轮保留了旧横幅；后续已按共同确认的方案改为紧凑资料布局，见[网格顶部横幅改造](网格顶部横幅改造.md)。
