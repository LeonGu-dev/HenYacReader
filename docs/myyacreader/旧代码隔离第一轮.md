# 旧代码隔离第一轮

2026-11-08，本地构建与回归验证完成，待用户验收。本轮不升级书库版本，不迁移或删除用户数据。

## 遗留代码是否有影响

有些仍有影响。旧五页编辑器虽然已隐藏，之前仍会创建和填充几十个控件；它还有元数据保存分支和“追踪缺失期号”的菜单入口。它们增加了维护负担和运行时对象。

只把源码文件移到一个目录，不能保证减小程序。需要同时取消编译、Qt 资源和翻译扫描引用，并控制发行文件的来源。本轮同时处理这些入口。

## 已隔离的范围

| 实现 | 本轮处理 |
| --- | --- |
| 旧基本信息、作者、出版、情节、笔记五页表单 | 移除创建、填充、重置与旧字段保存分支 |
| 旧的“点击以覆盖”单行及多行控件 | 四个源码/头文件移到参考目录，从两个应用的控件构建清单移出 |
| 依赖旧表单的缺期追踪界面 | 移除菜单、协调器与对话框入口 |
| 当前单页信息编辑 | 保留；仍由 `ComicMetadataEditor` 提供字段 |
| 封面、逐本编辑、批量编辑、文件名生成及重命名 | 保留原来的事务和文件回滚逻辑 |

编辑器实现从 1,666 行缩减到约 760 行。完整旧文件放在 [legacy 隔离区](../../legacy/README.md)，不是用大量 `#if 0` 混在正式实现中。

隔离区包含两层资料：官方基线 `118213b9ad951cbe9391381877046935c4076a18` 的原版编辑器，以及本轮拆分前的工作区快照。后者包含此前的改造，不代表整份文件都已废弃。13 份快照各有来源路径与 SHA-256，格式化和 Git 换行规则保留其原始字节。

## 仍然保留的兼容依赖

| 实现 | 继续保留的原因 |
| --- | --- |
| 阅读列表、旧标签的数据库表和迁移 | 旧书库读取、最爱迁移、外键关系仍需要它们 |
| 阅读列表模型、记录类型和导航支持 | 其他动作、服务端、占位记录等仍有引用，不能只删窗格对应的底层文件 |
| CBL 交换 | 桌面书单导入导出、导入结果匹配仍有调用；复查未发现当前服务端调用 |
| 占位记录底层处理 | 编辑、扫描匹配、列表记录及服务端仍使用；与缺期范围生成器分开处理 |
| 缺期生成器 `tracked_issues.*` | 本轮仍在构建清单；移除旧表单后，复查仅剩自身与测试引用，可作为下一轮独立隔离对象 |
| 旧专业元数据列 | 扫描、导入、XML、服务端和迁移仍使用；编辑新字段时继续保留旧值 |
| 网络服务、Comic Vine、3D Cover Flow、PDF/EPUB | 未在本轮取消；独立裁剪会影响功能与依赖，需要另行确认范围 |

因此这是第一轮安全拆分，没有把仍有引用的底层模块标成“已隔离”。

## 构建与发行入口

- CMake 递归检查构建目标的源码、接口源码及 include 目录，发现 `legacy/` 就拒绝配置；隔离区本身也拒绝被 `add_subdirectory`。
- 审计脚本验证快照哈希、Ninja 构建图、翻译项目和 Qt 资源，检查参考代码未进入这些输入。
- 发行暂存从一个**尚不存在的新目录**开始，按名称部署三个应用、Qt、解压/PDF/加密运行库、语言文件、服务端静态文件和原有许可证说明。
- 正式暂存排除 QML 调试插件。不复制整个仓库、构建目录或历史验收目录。
- 暂存后再次审核文件类型、目录和可执行程序名单，拒绝源码、测试程序、测试漫画、书库数据库、配置及参考文件；在目录外输出逐文件 SHA-256 清单。

在仓库根目录运行：

```powershell
& scripts/local/build-baseline.ps1 -Step Build
& scripts/local/build-baseline.ps1 -Step Test
& scripts/local/stage-release.ps1
```

最后一个命令默认创建带时间戳的新目录。也可以传入 `-OutputDirectory artifacts/releases/自定义名称`。日志位于工作区 `artifacts/logs`，清单为输出目录旁的 `.manifest.json` 文件。

本机本轮可运行目录：`D:\GitHub\comic-reader\artifacts\releases\isolation-v1`。直接运行其中的 `YACReaderLibrary.exe`，阅读器为同目录的 `YACReader.exe`。它是经过审计的发行暂存，尚未制作安装器或签名。后续安装器应只消费这份受控目录，不再从整个工作区取文件。

## 验证和体积

- 三个应用 Release 构建成功，完整 CTest **54/54** 通过，耗时 71.83 秒。
- 新增真实临时书库测试：不修改直接保存、批量和逐本编辑、文件与数据库同步重命名、自定义封面；检查未编辑的旧字段和新元数据得到保留。
- 新增 CMake 检查的正反例，确认普通目标正常配置、引用隔离文件的目标被拒绝。
- 13 份参考快照哈希一致，构建、翻译与 Qt 资源未包含隔离区；发行目录审计通过。
- 清除开发环境 DLL 路径后，三个程序的 `--version` 均返回 0。Reader 此命令会打印线程“拒绝访问”警告；对照原始 baseline 和之前的验收程序均相同，本轮未改动其启动实现。此检查验证依赖加载，不替代实际阅读的人工验收。

| 度量 | 结果 |
| --- | --- |
| 隔离前书库 exe | 6,101,504 字节 |
| 隔离后书库 exe | 5,976,064 字节 |
| 书库 exe 减少 | 125,440 字节，即 122.5 KiB，约 2.1% |
| 干净发行暂存 | 1,404 个文件，191,905,210 字节，约 183.02 MiB，未压缩 |

体积对比基于同一台机器的 Release 构建；原始书库 exe 和校验信息暂存在工作区 `artifacts/isolation-baseline`。发行目录仍包含三个程序、Qt 运行库以及 Microsoft VC 运行库安装程序。库管理 exe 的缩减不等于整个安装包同比缩减；后续若需要明显缩小包体，主要应评估仍在使用的可选功能与运行依赖。
