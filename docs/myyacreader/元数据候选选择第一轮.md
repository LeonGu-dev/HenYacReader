# 元数据候选选择第一轮

按已确认的交互预览实现。编辑页支持作者、社团、作品、角色、tag、即卖会、译者的候选选择。

- 点击输入框（或右侧的小箭头），在字段下方展开候选。一次只展开一个；点击另一个输入框后收起前一个，若新字段支持候选则展开新字段。
- 点击候选后填入字段，保持展开。再次点击已选候选取消选择；箭头可手动收起。
- 角色/tag 和合同本作者允许多选；单作者及其他单值字段替换当前值。手动输入、增减行、文件名解析继续可用。
- 选中候选使用与左侧筛选相同的描边：明亮黑色、暗黑白色。复用同一标签组件及配色存储，已有自定义颜色继续生效。
- 原创选择继续联动作品和角色；从原创角色切换为具体角色时清除原创占位值。
- 候选区域高度最多 180 个逻辑像素，内容过多时纵向滚动，不通过候选数量无限撑大编辑窗口。
- 展开和选择仅修改草稿，仍按原保存流程写入；取消编辑不会写入候选选择。

## 数据边界

`PropertiesDialog` 将当前 `databasePath` 对应的候选提供给编辑器。`DBHelper::metadataVocabulary()` 只查询该连接内仍有文件的漫画和占位记录，不读取其他书库、当前文件夹或阅读列表的筛选结果。多值拆分、去空、去重后排序。首次展开时读取，切换编辑记录时失效，避免连续编辑时使用上一条漫画的选中状态或旧候选。

使用独立命名的只读 SQLite 连接，不替换可能仍在使用的保存/导入连接，也不读取其他连接中尚未提交的草稿；空路径或不可用数据库返回空候选，不回退到其他库。

批量编辑的混合值仍保持未修改，只有用户实际输入或选择的字段才进入保存补丁；展开候选不产生修改。

## 组件与扩展

- `custom_widgets/metadata_value_chips.h`：筛选和编辑共用的标签绘制、换行、颜色和描边。
- `custom_widgets/metadata_picker.*`：输入区域旁的小箭头、可收起的候选区及有界滚动。
- `custom_widgets/compact_disclosure_button.h`：细线小箭头，文字与箭头间预留独立间距。
- `ComicMetadataEditor`：控制单个展开、单/多值写入及现有原创和合同本规则。
- 新增候选字段时，在词库查询和编辑字段登记处接入；布局和标签样式可以复用。

同时将筛选窗格折叠提示从「类型与状态」改为「筛选项」，为箭头与文字留出约 8 像素间距；侧栏与智能列表编辑器同步。
