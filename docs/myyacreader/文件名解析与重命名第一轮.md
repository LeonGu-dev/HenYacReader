# 文件名解析与重命名第一轮

后续交互已改为生成后独立确认重命名，不再勾选“保存时重命名”；当前规则见[系列作与编辑窗格第二轮](系列作与编辑窗格第二轮.md)。本文保留第一轮解析格式及实现背景。

本轮在既有单页漫画信息编辑器中增加手动解析、可编辑预览、保存时改名。当前版本已由用户验收通过。

## 实现位置

- `YACReaderLibrary/comic_filename.h/.cpp`：括号分组、作者/社团、标题、作品、翻译、无修、译者及 tag 解析，名称生成和 Windows 名称校验。
- `YACReaderLibrary/comic_metadata_editor.h/.cpp`：显示源名称；解析结果填入现有字段；用当前编辑值生成名称；预览和勾选确认；切换漫画清除改名确认。
- `YACReaderLibrary/staged_comic_rename.h/.cpp`：同目录改名、大小写改名、失败恢复；不覆盖已有目标。
- `YACReaderLibrary/properties_dialog.cpp`：保存时在现有元数据事务中更新 comic.fileName/path；提交成功后确认文件改名，失败回滚；改变了当前文件路径的陈旧编辑记录会被拒绝。

沿用原 comic.id/comicInfoId 和文件 hash，不改变压缩包内容或阅读进度。两份共享 comic_info 的文件仍共享元数据，只改名当前文件。无数据库结构迁移。

文件系统与 SQLite 不是同一个原子事务：本轮覆盖正常错误/提交失败的恢复，不含进程被强杀或断电后的自动恢复日志。尚未提供批量改名。

## 使用流程与名称格式

1. 打开单本编辑页，点击“从文件名解析标签”。
2. 检查并编辑所需元数据，点击底部“生成文件名”。
3. 可以手工修改预览（不含扩展名），勾选“保存时重命名压缩包”，再保存。
4. 未勾选时只保存元数据；关闭不保存不执行改名。

生成：`[社团 (作者)] 标题 (作品) [tag1] [tag2] [中国翻訳/AI翻译] [無修正] [译者].原扩展名`。无社团时用 `[作者]`；空项省略，段间一个空格，多作者以 `、` 分隔。仅无修输出修正标记。翻译标题、角色和彩色状态不写入文件名。

识别使用括号结构和状态关键词，支持全角括号、圆/方括号混用及部分顺序变化；不含“無修正”时不推断有码。仅写入识别到的字段，独立作者会清空社团。圆括号优先作作品；无圆括号时标题后首个未归类方括号暂作作品；有翻译状态时末尾方括号可能作译者，其余候选进入 tag。这些存在歧义，保存前需人工核对；界面不额外显示解析说明。

保留原目录与扩展名，不覆盖已有目标，非法 Windows 名称会拒绝。自动生成时将非法标点替换为对应全角字符，供核对。批量/缺失记录/占位漫画不显示此功能。
