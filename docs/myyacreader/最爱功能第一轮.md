# 最爱功能第一轮（待验收）

## 界面与操作

- 漫画列表在最左侧加入 `♥` 列，灰心为未收藏，红心为已收藏。单击立即保存；双击爱心不打开漫画。
- 编辑漫画信息在标题、翻译标题与作者之间增加“最爱”。点击灰／红心切换，随“保存”写入；关闭而不保存不修改书库。
- 批量编辑遇到不同收藏状态时显示带横杠的灰心；不点击保留各自状态，点击后统一设置。
- 左侧 Favorites 及原“添加到 Favorites”、拖入 Favorites、从 Favorites 移除都使用同一个元数据字段。
- 旧表头配置保留其他列的顺序与宽度，自动补上最左侧 40 像素爱心列。

## 存储与迁移

- 数据库版本从 `10.5.1` 升为 `10.5.2`，新增 `comic_info.favorite`，按共享漫画信息保存，而不是按文件位置保存。未设置按未收藏处理。
- 相同内容的多个文件共享一份收藏状态；标题相同但内容不同的文件不因此共享状态。
- 书库升级沿用现有备份、事务和回滚机制。任一旧文件已收藏，则对应漫画信息标为收藏；迁移成功后清除旧收藏成员关系，避免维护两份状态。
- `placeholder` 同步增加字段以保持编辑器和元数据补丁一致；左侧 Favorites 当前只列出现存漫画文件。
- Favorites 支持现有表头排序；本轮不再维护原收藏列表的手工拖动顺序。
- 阅读进度更新保留收藏字段，不把收藏加入文件名生成格式。
