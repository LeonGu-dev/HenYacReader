# MyYACReader 项目文档

基于官方 YACReader develop `118213b9ad951cbe9391381877046935c4076a18`，保留上游历史、独立 Library / Reader 架构及 GPL v3 许可证。书库按小步修改、用户验收推进；轮次文档记录各自阶段，不代表当前全部待验收。

当前总览见 [书库阶段总结与遗留审查](书库阶段总结与遗留审查.md)（2026-11-11），包含已完成改动、数据通路遗留和验证范围。

最新状态见 [书库阶段收尾检查](书库阶段收尾检查.md)（2026-11-12）：当前完整构建与 56/56 回归通过，主要功能闭环；封版前仍建议统一旧已读／未读及阅读方式写入失败处理，并完成阶段归档。

## 各轮实现记录

[书库菜单与元数据清除整理](书库菜单与元数据清除整理.md)：高级修复分组、隐藏旧数据交换与信息入口、添加到普通阅读列表、清除整理信息和阅读状态并保留封面／书单、写入失败处理及旧编号展示调整。

[系列作与编辑窗格第二轮](系列作与编辑窗格第二轮.md)：单值系列及筛选、原位候选、评分与最爱、标签输入及独立重命名。

[网格顶部横幅改造](网格顶部横幅改造.md)：紧凑资料布局、共用 Info view 展示配置、响应式封面区域及长标签展开。

[遗留入口关闭与网格横幅说明](遗留入口关闭与网格横幅说明.md)：关闭旧整理、旧标签、残留快捷键及 Comic Vine 配置入口；说明旧网格横幅的实际位置和显示条件。

[元数据候选选择第一轮](元数据候选选择第一轮.md)：输入框下展开候选、保持多选、自动切换和小箭头收起；筛选项提示及箭头间距同步调整。

[文件夹删除二次确认](文件夹删除二次确认.md)：红色垃圾桶与警告、路径保留原色，两次确认后才删除。

[Info view 元数据改造](Info-view元数据改造.md)：紧凑资料行、现有元数据与颜色同步、状态展示、可折叠文件信息及集中字段配置。

[页签与工具栏细节调整](页签与工具栏细节调整.md)：四项页签加左右导航、即卖会列宽更新、最爱表头居中、工具栏精简及 Esc 退出全屏。

[筛选展开与折叠](筛选展开与折叠.md)：单色图钉、状态区独立滚动、折叠摘要及侧栏/智能列表分别记忆偏好。

[即卖会元数据第一轮](即卖会元数据第一轮.md)：编辑、文件名解析与生成、彩色标签列、筛选及智能列表同步扩展。

[智能列表编辑第一轮](智能列表编辑第一轮.md)：复用左侧筛选组件、独立编辑草稿、当前书库文件夹选择及自适应窗口。

[保存筛选为列表第一轮](保存筛选为列表第一轮.md)：加号菜单保存筛选条件为动态智能列表，或将当前结果保存为静态普通列表；隐藏匹配、tag、铅笔和旧语法新建入口。

[阅读列表改造第一轮](阅读列表改造第一轮.md)：顶部恢复「正在阅读」「最近添加」两行并重做规则；窗格背景改为透出侧栏主题。

[清理默认列表第一轮](清理默认列表第一轮.md)：阅读列表窗格不再显示 Favorites、Reading、Recent，收藏只走元数据；为改造用户书单做准备。

[恢复阅读列表窗格](恢复阅读列表窗格.md)：阅读列表位于文件夹、筛选下方，三窗格可调整高度并保存；先恢复原入口，后续再简化为用户书单。

[旧代码隔离第一轮](旧代码隔离第一轮.md)：移出旧编辑表单和专用控件，保留参考快照，增加构建检查与干净发行暂存入口。

[筛选表头与布局调整](筛选表头与布局调整.md)：最爱筛选、表头与／或切换、重置联动和条件区上移。

[类型与侧栏窗格第一轮](类型与侧栏窗格第一轮.md)：类型元数据及筛选，移除阅读列表窗格，筛选表头可拖拽并保存高度。

[最爱功能第一轮](最爱功能第一轮.md)：收藏元数据、最左侧爱心列、编辑页开关及旧收藏迁移。

[元数据筛选第一版](元数据筛选第一轮.md)：新增左侧筛选窗格，支持 tag／作品／作者、与／或及状态组合。

[作品、角色和 tag 颜色自定义](标签颜色自定义.md)：右键首项更改颜色，使用系统选择器并持久保存。

[列表列与表头菜单第一版](列表列改造第一轮.md)：13 列、彩色标签、排序和列配置。当前工作区在已验收版本上继续开发，本轮尚未提交。
