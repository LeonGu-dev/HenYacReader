## 当前待验收

[恢复阅读列表窗格](恢复阅读列表窗格.md)：阅读列表位于文件夹、筛选下方，三窗格可调整高度并保存；先恢复原入口，后续再简化为用户书单。

[旧代码隔离第一轮](旧代码隔离第一轮.md)：移出旧编辑表单和专用控件，保留参考快照，增加构建检查与干净发行暂存入口。

[筛选表头与布局调整](筛选表头与布局调整.md)：最爱筛选、表头与／或切换、重置联动和条件区上移。

[类型与侧栏窗格第一轮](类型与侧栏窗格第一轮.md)：类型元数据及筛选，移除阅读列表窗格，筛选表头可拖拽并保存高度。

[最爱功能第一轮](最爱功能第一轮.md)：收藏元数据、最左侧爱心列、编辑页开关及旧收藏迁移。

[元数据筛选第一版](元数据筛选第一轮.md)：新增左侧筛选窗格，支持 tag／作品／作者、与／或及状态组合。

[作品、角色和 tag 颜色自定义](标签颜色自定义.md)：右键首项更改颜色，使用系统选择器并持久保存。

[列表列与表头菜单第一版](列表列改造第一轮.md)：13 列、彩色标签、排序和列配置。当前工作区在已验收版本上继续开发，本轮尚未提交。
