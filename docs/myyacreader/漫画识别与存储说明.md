# 数据存储与文件识别

元数据存于书库根目录下 `.yacreaderlibrary/library.ydb`，封面位于同目录 `covers`，`id` 标识书库。这里的数据库、INI 配置和漫画压缩包均为本地数据，不提交版本控制。

## 文件记录与共享信息

- `comic`：每份文件自己的 ID、文件名、相对路径和 `comicInfoId`。
- `comic_info`：漫画的指纹、标题、作者、标签、阅读进度等信息。
- 多份文件可指向同一个 `comic_info`；共享信息的改动会影响它们，但重命名只修改当前文件的 `comic` 记录和磁盘名称。
- 标题不作为唯一键，不同内容版本可以同名。

## 快速指纹

上游的 `library_creator.cpp::pseudoHash()` 使用：

`SHA-1(文件开头 524288 字节) + 文件总字节数的十进制文本`

不足 512 KiB 时读取全部字节。这是快速文件指纹，不是逐页内容识别，也不是对所有字节求哈希。此前已只读验证：两个不同语言文件名可以具有相同指纹并共享漫画信息。重新打包或更换翻译后可能不再相同。

## 新增信息

当前数据库版本为 10.5.5，累计新增 `translatedTitle`、`circle`、`work`、`isAnthology`、`censorship`、`translationStatus`、`translator`、`favorite`、`publicationType`、`convention`、`seriesName` 十一列；标题、作者、角色、tag、彩色状态和评分复用原列。多值以换行分隔。原 ID、已有列、文件关联和进度保留。字段集中定义于 `common/descriptive_comic_metadata.cpp`。

标签自定义颜色在应用 INI 配置中，不在书库数据库内。旧“导出／导入漫画信息”尚未覆盖上述新增字段，不可作为完整新版元数据备份；详见 [阶段审查](书库阶段总结与遗留审查.md)。

路径定义在 `common/yacreader_global.h::LibraryPaths`，数据库读写主要在 `YACReaderLibrary/db/data_base_management.cpp` 与 `YACReaderLibrary/db_helper.cpp`。
