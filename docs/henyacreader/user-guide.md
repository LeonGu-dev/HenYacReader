# 使用说明

## 开始使用

解压完整 ZIP，运行 `YACReaderLibrary.exe`。在“库”处新建书库或打开已有书库；漫画原文件保留在自己管理的文件夹中。双击漫画调用独立阅读器。

## 元数据编辑

右键漫画选择编辑。标题不要求唯一，标题翻译按需启用。作者通常单值，合同本启用多作者；取消合同本先保留草稿，保存后按单作者覆盖。系列启用后填写单个系列名。

点击即卖会、作者、社团、作品、角色、tag、译者、系列等输入区，可展开当前库已有候选。多值可连续点击选择，点击箭头、另一个字段或空白处收起。可手工输入新值；角色和 tag 支持多个值。作品／角色选择原创时联动，原创候选置顶。

评分与最爱直接点选。状态按钮再次点击可取消为未设置；类型支持同人志、单行本、杂志、插画集。普通编辑点击保存后写入书库。

## 文件名

“从文件名解析标签”使用本地规则匹配，结果需复核；缺少无修正标记不会自动推断有码。常见格式：

`(C107) [社团 (作者)] 标题 (作品) [tag] [中国翻訳] [無修正] [译者].zip`

“生成文件名”展开可修改的新名称预览；点击“重命名文件”独立执行。关闭预览不改文件；保存元数据不自动改名。保留扩展名，拒绝同名冲突并同步书库路径。

## 列表与筛选

表头右键可调整显示列，宽度与顺序可记忆。标签右键可修改颜色。系列可筛选但不显示为列表列。

左侧筛选支持 tag、作品、作者、即卖会、系列及评分；候选搜索仅查找下方标签。与／或按钮控制名称类条件；评分内部取或，评分、最爱、色彩、修正、类型和翻译与其他结果取交集。重置清除所有条件并恢复与筛选。

页签可用小箭头或滚轮切换。图钉控制始终展开，筛选项可收起／滚动；三个侧栏窗格可拖动调整高度。

## 阅读列表

普通列表独立于磁盘文件夹。右键漫画“添加到阅读列表”可加入普通书单；也可保存当前筛选结果为静态普通书单。智能列表保存条件，按书库或指定文件夹动态匹配；编辑复用筛选面板。文件夹范围仅含直属漫画，不递归子目录。

智能列表不基于另一个阅读列表成员，也不保存主搜索框文字；候选搜索文字同样不作为条件。目录改名不使范围失效，删除目录后结果为空。

## 维护与删除

书库名称右侧菜单提供更新、改名、移除、数据库备份／恢复和打开目录。“高级修复”收纳封面与页数修复、数据库修复、访问恢复、重新扫描漫画元数据。后者读取压缩包内 XML，可能覆盖已有字段；封面修复本身不导入 XML。

删除漫画或文件夹使用红色警示和二次确认。普通书单中的删除仅移除成员；物理文件夹或智能列表中删除实际文件时会明确提示。默认选否，Esc 或关闭窗口取消。

“删除元数据”同时清除整理字段、最爱、评分、已读、进度和书签，保留封面、文件及普通书单归属；智能列表会重新匹配。共享同一漫画信息的文件副本会一起受到元数据修改影响。
