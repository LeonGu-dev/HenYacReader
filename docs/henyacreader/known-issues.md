# 已知限制与后续维护

0.1.0 为书库阶段基线，正常流程已完成 56 组回归。以下项目已记录，不阻止本次阶段收尾：

- 旧的批量已读／未读、继续阅读中设为未读、阅读方式修改，未完整检查写库结果；数据库只读、锁冲突或提交失败时可能出现显示与保存不一致。后续统一成功后更新、批量失败回滚。本阶段未扩展修复这些路径。
- 普通书单底层按漫画信息关联；同指纹不同文件可能共享元数据／评分／进度。标题相同不导致合并。
- 文件夹智能范围不递归子目录；系列暂无卷序号和文件名语法。
- 文件名解析为粗略本地规则，需人工复核，不是联网识别。
- 自定义标签颜色存在应用配置，复制书库不会自动携带。
- 旧语法智能书单仍可读取／编辑；部分已隐藏模块仍参与构建，保留兼容代码，不做本阶段的大规模裁剪。
- Qt 最大化窗口退出全屏有窗口状态过渡；小屏幕或长标签仍可能需要滚动。
- 尚未完成大规模真实书库性能基准、自动翻页、统一整体 UI、macOS／Linux 发行、安装包和签名。

程序保留上游内部名与 EXE 名用于兼容。使用本项目 Releases 手动更新，不用官方 YACReader 安装包覆盖改造版。升级前备份书库数据库和应用配置。
