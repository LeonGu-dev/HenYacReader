# 数据与兼容

书库根目录的 `.yacreaderlibrary/library.ydb` 保存元数据、评分、最爱、进度和阅读列表；封面在同目录 `covers`。漫画压缩包不在这个数据目录中。

数据库版本为 10.5.5，与 HenYacReader 应用版本 0.1.1 独立。字段集中定义在 `common/descriptive_comic_metadata.*`。不同文件使用独立文件记录，可以共享漫画信息；标题不是唯一键。指纹沿用上游算法：文件开头最多 524288 字节的 SHA-1，拼接文件大小。它不是完整内容哈希，同内容改名可共用信息，重新打包后可能不同。

普通书单成员另存关联表；清除漫画元数据不删除该关联。重命名只修改当前文件路径，不重写压缩包内部内容。

数据库备份是数据库的历史快照，包含新增字段、书单和进度，不含封面／漫画文件。关闭所有使用书库的程序后，完整复制 `.yacreaderlibrary` 可保留数据库和封面；完整漫画备份还需复制原漫画文件。重要备份应另存一份。

应用设置、列宽和自定义标签颜色保存在用户配置中，不随书库自动迁移。`YACREADER_DATA_DIR` 可用于隔离测试配置及 IPC，但本版本默认仍使用原配置位置。

为了兼容已有安装，运行文件名、组织／应用配置标识、`.yacreaderlibrary` 路径和 `myyacreader:metadata-filter:v1/v2/v3:` 智能书单前缀保留。不可为改名直接替换这些标识。不要让两个应用同时修改同一书库。

旧元数据导入／导出未覆盖所有新增字段，入口已隐藏，不作为完整备份方式。更新来源为本仓库 Releases，阅读器不再自动提示安装上游官方版。
