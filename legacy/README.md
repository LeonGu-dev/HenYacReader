# 旧代码参考隔离区

本目录只供阅读、比较和摘取设计思路，不参与编译、翻译扫描或发行暂存。
不要直接 include、链接或安装这里的文件。需要恢复功能时，应把经过评审的实现移回正式源码目录，并补充验证。

## 目录

- `reference/upstream-118213b/`：克隆的官方基线 `118213b9ad951cbe9391381877046935c4076a18` 中的旧编辑器原文。
- `reference/before-ui-isolation/`：2026-11-08 本轮拆分前的完整文件快照，包含此前已验收的改造，以及尚未清除的旧实现。不是整份文件都已废弃。
- `reference-manifest.json`：各快照的来源与 SHA-256，可用 `scripts/local/check-reference-isolation.py` 验证。

## 本轮退出正式代码的实现

- 旧编辑器的基本信息、作者、出版、情节、笔记五个标签页，以及隐藏控件的创建、填充与重置。
- 依赖这套旧表单的“追踪缺失期号”菜单及对话框入口。
- 不再使用的编辑器字段访问函数、日期与阅读类型的旧表单保存分支。
- 仅供旧表单使用的 `YACReaderFieldEdit` / `YACReaderFieldPlainTextEdit` 控件；已从两个应用的公共控件构建清单移出。

正式编辑器仍在 `YACReaderLibrary/properties_dialog.*`，保留封面、批量编辑、逐本编辑、事务保存和文件重命名，并使用当前的 `ComicMetadataEditor`。

## 尚未隔离的兼容代码

旧阅读列表的数据表、迁移、模型、服务端与 CBL 交换逻辑还有实际引用；旧元数据列也被导入、扫描、服务端和迁移使用。这些继续编译或保留数据，不能仅因对应窗格已隐藏就移走。后续逐项替换后再隔离，避免破坏已有书库。

## 防止误引入

根 CMake 在配置时检查所有构建目标的源码和 include 目录，拒绝 `legacy/`；这里的 CMakeLists 也拒绝被 add_subdirectory。参考文件使用自己的格式配置，保留原始字节。

发行入口为 `scripts/local/stage-release.ps1`，从空目录按运行依赖清单部署，不打包工作区。源码、参考快照、历史验收程序、测试书库和用户配置均不属于发行输入。不要用整个仓库或 `artifacts/table-v1` 生成安装包。
