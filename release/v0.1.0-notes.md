# HenYacReader 0.1.0

首个书库阶段版本，基于 YACReader 10.5.0 develop 改造，支持 Windows x64。

发行前完整 Release 构建通过，CTest 56/56 通过（82.76 秒）。

## 下载与使用

下载 `HenYacReader-0.1.0-windows-x64.zip` 并完整解压，运行 `YACReaderLibrary.exe`。单独阅读可运行 `YACReader.exe`；请保留解压目录中的 DLL 和插件。缺少 VC++ 运行库时，可运行包内 `vc_redist.x64.exe`。

这是免安装运行包；配置默认仍位于用户配置目录，不是所有设置都跟随 ZIP 移动。EXE 名称、配置标识和 `.yacreaderlibrary` 路径保留兼容。升级前备份书库数据库与应用配置。

## 本阶段内容

- 新版元数据、标签候选、即卖会、系列、最爱和评分。
- 组合筛选、普通阅读列表、静态快照与共享筛选组件的智能列表编辑。
- 文件名解析、生成预览、独立重命名和书库路径同步。
- 紧凑资料视图／网格横幅、可调整侧栏、书库高级修复菜单。
- 元数据清除保留封面及普通书单归属；删除使用红色警示及二次确认。
- 项目改名、文档清理；旧过程记录保存在 Git 历史。

## 已知边界

旧已读／未读及阅读方式的写入失败处理为后续维护项；文件名解析需人工复核；标签颜色保存在应用配置；未完成大库性能基准、自动翻页、其他平台发行或安装包签名。本轮不继续扩大书库功能范围。

本项目采用 GPL v3，原项目作者及第三方署名保留。源码见本标签，详细说明见 `docs/henyacreader/`。当前仓库私有，下载需仓库权限；后续对外发行时可另行调整可见性。

附带 `.sha256` 校验文件与逐文件 `.manifest.json`。ZIP 已与审计清单逐文件校验，不包含个人书库、测试漫画、应用配置或历史验收目录。
